# FieldFlow

Demo Next.js site for FieldFlow, a fictional B2B field-service scheduling product.

Public hostname: `https://fieldflow.demo.sageobot.com`

## Run locally

```bash
npm install
npm run build
npm run start
```

The homepage and an empty `/blog` work with no seoengine env vars. Copy `.env.example` to `.env.local` and fill `SEOENGINE_API_URL`, `SEOENGINE_API_KEY`, and `SEOENGINE_SITE` when the blog is wired.
